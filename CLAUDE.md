# Parsimony (раньше «Напоминалка») — контекст проекта для Claude Code

Это **короткое ядро**: что за проект, файлы, правила работы и действующие решения. История по датам, разборы вариантов, «что пробовали и убрали», подробные описания и проверки — дословно в **`docs/history.md`** (разделы в прежнем порядке). Ссылка «→ history: «Название»» — раздел `docs/history.md`, заголовок которого начинается с этих слов; «см. «…»» в тексте ниже — раздел этого файла, а если такого здесь нет — раздел `docs/history.md`. Прежде чем менять какую-то часть приложения, прочитай её раздел там.

**Как вести эти файлы.** Сюда — только 1–3 строки о том, как устроено сейчас, и ссылка. Подробности новой работы (что сделано, варианты, решения пользователя, проверки) — в `docs/history.md`: в конец подходящего раздела или новым разделом в конец файла. Личные планы — в `CLAUDE.local.md`, их дневник — в `CLAUDE.local-history.md` (оба не в git).

## Что это
PWA-календарь-планер **Parsimony** (название — константа `APP_NAME` в `js/core.js`; ключ данных и адрес сайта прежние). Пользуются на iPhone (установлено на экран «Домой») и на ПК в браузере.
Хостинг: GitHub Pages, репозиторий `greed1-alt/Pars1m0ny-s_helper`, ветка `main`, корень репозитория.
Адрес сайта: **https://app.parsimony.ru/** (с 9 октября 2026, см. «Свой адрес»). Старый https://greed1-alt.github.io/Pars1m0ny-s_helper/ сам перенаправляет туда.

## Файлы
Без сборщика: обычные `<script>` по порядку, у всех файлов общие глобальные переменные. Данные — в localStorage (ключ `remapp_v1`).
- `index.html` — разметка и подключение файлов.
- `css/fonts.css` + папка `fonts/` — свои шрифты (Inter, Josefin Sans 300 для надписи) вместо Google Fonts, лицензия OFL рядом; см. «Свои шрифты».
- `css/app.css` — запасные дизайн-токены (`:root`, темы), календарь, окна. `css/sections.css` — разделы, графики, нижние вкладки. `css/ui2.css` — экраны интерфейса, карточки, оформление, подсказки «?».
- `js/core.js` — данные `S`, `migrate()` + `onMigrate()` для разделов, реестр действий `ACT`, иконки, даты, повторы, ввод фразой `parseNL`.
- `js/names.js` — недоступные имена и ники: мат, оскорбления, служебные (`nameBad`, см. «Недоступные имена и ники»).
- `js/a11y.js` — доступность: окна (фон `inert`, фокус внутрь и обратно — `a11ySheet` / `a11yOpen` / `a11yClose`), фокус после перерисовки (`focSave` / `focBack`), Enter и пробел у `role="button"`, стрелки по дням «Месяца», подписи для диктора (`a11yMarks`), заголовок вкладки по разделу (`pageTitle`), «уменьшить движение» (`smoothB`). См. «Доступность».
- `js/look.js` — оформление: палитры `PAL`, контраст, вид карточек, углы, цвет событий; `applyLook()` ставит цвета переменными CSS; блок «Оформление» в Настройках (`lookHTML()`).
- `js/help.js` — подсказки «?»: тексты `HINTS`, `hint(текст)` / `hintK(ключ)`, всплывающее окошко `#tip`.
- `js/calendar.js` — виды календаря, `render()`, боковая панель, карточка события, настройки, меню команд, `snap()`/`undo()`.
- `js/charts.js` — графики SVG (линия/волна, столбики, кольцо, «пончик») и подсказка при наведении.
- `js/sections.js` — переключение разделов `SEC`/`setSec`, плашка «Вы пропустили», пример для пробы, общие функции месяца и денег.
- `js/tasks.js`, `js/habits.js`, `js/finance.js` — разделы «Задачи», «Привычки», «Финансы».
- `js/goals.js` — раздел «Цели»: цели со сроком и шагами, темп, подначки и похвалы.
- `js/timer.js` — экспериментальный раздел «Таймер».
- `js/tour.js` — подробное знакомство: тур по каждой странице с подсветкой элементов (`TOURS`, `tourStart`), окно «Знакомство» (`openTourMenu`), приглашение «Впервые здесь?» (`tourInvite`).
- `js/layout.js` — расположение: какие разделы включены и в каком порядке (`S.settings.secs`, `navSecs()`, `secOn()`), блоки Главной (`S.settings.home`, `HOME_BL`, `homeOrder()`), окна «Разделы» и «Главная».
- `js/ui2.js` — интерфейс: единая строка ввода, сворачиваемые блоки, экраны Главная / Задачи / Финансы / Привычки (`homeHTML`, `tasksHTML`, `financeHTML`, `habitsHTML`), знакомство при первом запуске.
- `js/pages.js` — страницы «Главная», «Профиль», «Настройки» (блоки настроек — `settingsBlocks()` в calendar.js), аватар `avatarHTML()`, достижения `ACH`.
- `js/friends.js` — друзья: своя карточка для друзей и что они видят, заявки, ссылка-приглашение, таблица недели, страница друга (см. «Друзья»).
- `js/chat.js` — переписка с друзьями: окно (список → переписка), кнопка «Сообщения» в шапке, реакции, событие из календаря (см. «Друзья»).
- `js/cloud.js` — аккаунт и синхронизация: вход по коду из письма, запись в `user_data`, объединение изменений с разных устройств, выход и удаление аккаунта (см. «Аккаунты»).
- `js/assistant.js` — ИИ-помощник: чат, голосовой ввод, записи сразу с «Отменить» (см. «ИИ-помощник»).
- `js/map.js` — точка на карте у события (Leaflet + OpenStreetMap, см. «Правки бета-тестеров»). Библиотека — `vendor/leaflet/` (Leaflet 1.9.4, BSD-2, с лицензией), грузится только при открытии карты.
- `js/input.js` — нажатия, клавиши, перетаскивание, свайпы. `js/share.js` — «Поделиться», копия в файл. `js/notify.js` — напоминания на устройстве (подписка, «Проверить», переход к дню по уведомлению), обновление раз в 30 с. `js/main.js` — запуск.
- Новое действие по кнопке: `data-act="имя"` в разметке + `ACT.имя = (el, ev) => …` в файле раздела (так каждое действие — отдельная функция для будущего ассистента).
- `sw.js` — service worker: офлайн-кэш (список `FILES` — все файлы выше) и приём пуш-уведомлений. Приложение открывается сразу из кэша своей версии, новая скачивается в фоне, и страница перезагружается сама, когда человек ничего не делает (`swUpdated` в `main.js`, см. «Скорость открытия»).
  **При каждом изменении файлов приложения увеличивай версию `CACHE` (`rem-vN` → `rem-vN+1`)**, иначе iPhone покажет старую версию. Новый файл — добавь в `FILES`.
- `manifest.json`, `icon-180.png`, `icon-192.png`, `icon-512.png` — установка на «Домой».
- `privacy.html` — политика обработки персональных данных, `consent.html` — согласие на обработку (отдельный документ), `beta.html` — памятка бета-тестера: статичные страницы без скриптов, со своим CSP. Меняется то, на что давали согласие, — новая дата редакции в обеих страницах и `CONSENT_V` в `js/cloud.js` (см. «Политика и согласие»).
- `docs/history.md` — архив этого файла. Не часть приложения: в `FILES` в sw.js не входит, на бету не выкладывается, при его правке версию кэша не поднимать.

## Сервер (Supabase)
- Проект `zgasnvubcdprgsypkglh`. Таблицы: `user_data` (записи, см. «Аккаунты»), `profiles`, `friends`, `admins`, `fr_stats` (честные очки), `fr_notify` (очередь пушей о заявках) — друзья, `supabase/sql/friends.sql`; `messages`, `msg_notify` (очередь пушей о сообщениях) — переписка, `supabase/sql/messages.sql` (после friends.sql), `feedback` (отзывы), `push_subscriptions` (подписки устройств на напоминания, `user_id`), `reminder_log` (что уже отправлено), `ai_usage` (счётчик помощника). SQL — `supabase/sql/`, выполняет пользователь в SQL Editor.
- Edge Functions (код — `supabase/functions/`): `reminders` — напоминания и сводки раз в минуту по pg_cron; `assistant` — ИИ-помощник. Публикует пользователь вручную: Edge Functions → функция → Code → Deploy. «Verify JWT» выключен — доступ проверяется внутри. Ключи (VAPID, `AI_PROVIDER`, `GIGACHAT_AUTH_KEY`) — Edge Functions → Secrets, общие для всех функций.
- `clever-task` удалена 11 октября 2026: её тест слал уведомление на устройства всех друзей. Проверять — кнопкой «Проверить» в приложении, она шлёт только на свои устройства.
- **Никогда не добавляй в репозиторий секретные ключи** (приватный VAPID, `service_role` / `sb_secret_...`). Репозиторий публичный. В index.html допустим только publishable-ключ. Ключи Resend и GigaChat — тоже секреты: ни в чат, ни в репозиторий.
- Изменения в базе (новый SQL) должны работать и со старым кодом в `main`, пока не выпустили.
- → history: «Сервер (Supabase)» (история подписок).

## Как работать с пользователем
- Пользователь почти не программирует: объясняй по-русски, коротко и простыми словами.
- После правок: `node tools/check-js.mjs` (каждый файл и все вместе — ловит одинаковые глобальные имена в двух файлах), подними версию кэша в `sw.js`, затем коммит в `dev`, `git push origin dev` и `bash tools/deploy-beta.sh` — правка появится на **бете** https://beta.parsimony.ru за 1–2 минуты (см. «Бета и рабочая версия»).
- В `main` (рабочее приложение друзей, https://app.parsimony.ru) — **только когда пользователь скажет «выпускаем»**: `git checkout main && git merge --ff-only dev && git push origin main && git checkout dev`.
- Не создавай дубликаты файлов (вроде `index (1).html`).
- Показывай, что поменялось, и напоминай: на iPhone приложение нужно закрыть и открыть заново — через пару секунд оно обновится само (тост «Приложение обновлено — версия N»; с rem-v95, для версий до неё — иногда дважды).
- Тесты: `node tools/test-reminders.mjs` — перед каждым изменением функции `reminders` (сверяет её с `js/core.js`); `node tools/test-assistant.mjs` — перед изменением функции `assistant`; `node tools/test-names.mjs` — недоступные имена; `node tools/test-friends.mjs` — друзья и переписка (с `PGLITE_DIR` — весь SQL в настоящем Postgres: ник на сервере как в приложении, каждый видит только своё, писать — только другу). Перед выпуском — все тесты, `check-js`, поиск секретов в `main..dev`; команды выпуска — через `set -e`, не через `;`.

## Безопасность
- Пользовательский текст на экран — через `esc()`, подсказки графиков — `textContent`; ссылки — `safeUrl` (только http(s)), фото — `okImg`, цвета — `safeColor`.
- Всё чужое проверяется: файл копии и данные с сервера — `cleanTree` (`share.js`), ссылки «Поделиться» — `fromShared` / `unpackShare`; `migrate()` чинит id, цвета, даты.
- CSP в `index.html`: скрипты только свои, без встроенного кода; связь — сайт, `zgasnvubcdprgsypkglh.supabase.co`, `nominatim.openstreetmap.org`; картинки — свои, `data:`, `blob:`, `tile.openstreetmap.org`; шрифты и стили — только свои (`font-src 'self'`). **Новый внешний адрес нужно добавить в CSP**, иначе запросы будут заблокированы.
- RLS: в каждой таблице — только своя строка, у `anon` прав нет; `delete_my_account` (security definer) удаляет только вызвавшего. Ожидаемые предупреждения Security Advisor: `delete_my_account`, функции друзей (`friend_*`, `friends_list`, `invite_new`) и переписки (`msg_*`) — security definer, иначе чужое не показать; Leaked Password Protection; `ai_usage`, `fr_notify`, `messages`, `msg_notify` — «RLS без правил» (только через функции).
- **Чек-лист перед раздачей друзьям** (повторять перед каждым выпуском):
  1. 2FA на GitHub, Supabase, reg.ru и почте пользователя.
  2. Supabase → Advisors (Security) без предупреждений; RLS включён на всех таблицах.
  3. Два тестовых аккаунта: A не видит, не меняет и не удаляет данные B — проверка запросами с токеном A.
  4. «Вредные» данные во всех полях и в файле копии — ничего не выполняется.
  5. В консоли нет нарушений CSP.
  6. Поиск секретов в истории git.
  7. Ревью изменений: `/security-review` и `/code-review`.
- → history: «Безопасность», «Аккаунты» (проверка двумя аккаунтами).

## Устройство приложения (действующие решения)
Ориентиры дизайна — Notion Calendar (минимализм, тонкие линии, командное меню) и Яндекс Календарь; подробнее — `DESIGN-PLAN.md`. Правила пользователя: **в одном месте не повторяются никакие данные**; всё нажимаемое — кнопка или `role="button" tabindex="0"` (работает с клавиатуры), у полей — подпись (видимая `.fl` / `span` строки или `aria-label`; `a11yMarks` подставит подпись строки сама); у каждой непонятной детали — «?»; красный `--red` — только «сегодня» и «сейчас»; шрифт не мельче 12 px; поля ввода на телефоне 16 px (иначе iPhone увеличивает страницу).

### Данные и общее
- `S` — в localStorage `remapp_v1`. `migrate()` чинит и переносит старые данные, разделы добавляют своё через `onMigrate()`. `snap()` перед изменением → «Отменить» в тосте и Ctrl+Z (`UNDO_KEYS`).
- Событие: `repeat = {type: none|daily|weekdays|weekly|monthly|yearly, days:[0..6], until}`, выполненные дни повтора — `doneDates`, удалённые — `skip`; напоминания `reminder.offsets` (минуты до начала, читать через `remOffs(e)`); точка на карте `geo = [широта, долгота]`; задача — `task:true` + `prio` (urgent/high/mid/low), шаг цели — поле `goal`.
- Ввод фразой по-русски — `parseNL` («встреча завтра в 15:30 на час #работа»); деньги — `parseMoney(текст, вид)`, словарь `FIN_KW`.
- → history: «Большое обновление графики», «Блоки на страницах и несколько напоминаний».

### Навигация, шапка, окна
- Разделы — `SEC` / `setSec`; какие включены и в каком порядке — `S.settings.secs`, `navSecs()`, `secOn()` (Главная всегда первая). Выключенный раздел прячет вкладку, свои блоки и вид записи в строке ввода, данные не удаляются. Телефон — вкладки внизу (`#tabbar`); ПК — боковая панель: поиск, «+ Создать событие», мини-календарь (до 4 точек категорий под числом), «Мои календари» с галочками, «Шаблоны событий», свой блок раздела, внизу «Настройки», «Горячие клавиши», «Отзыв о бете».
- **«План» на телефоне**: Календарь и Задачи одной вкладкой (`planOn()`: ширина < 900 px, оба раздела включены, `S.settings.plan !== false`), в шапке «Месяц · День · Лента · Задачи». Внутри это два раздела.
- Шапка телефона: ‹ заголовок ›, кнопки ✦ помощник (`.hdr-ai`), лупа (`.hdr-sr`) и аватар — по 36 px (⚙ убран 22 октября 2026: Настройки — в меню профиля); текущий год в заголовке месяца не пишется (`ymHead`). ПК: заголовок, «‹ Сегодня ›», переключатель видов, справа «Помощник», имя (не длиннее 20 знаков, `NAME_MAX`) и аватар; ⚙ на ПК нет. Нажатие на имя / аватар (и на телефоне) — меню профиля `ACT.accmenu` (pages.js): кто вы, серия и очки недели, Премиум (скоро), Друзья / Лидеры / Достижения / Редактировать / Пригласить, внизу Настройки, тема и выход. «+» в шапке нет на Главной, в Календаре телефона, в Задачах (и на вкладке «Цели» — там строка «Новая цель», с 21 октября 2026), Привычках и Финансах — добавляют строкой ввода (`data-nonew`).
- Окна (`sheet()`): `#sh` — `role="dialog"`, заголовок окна — его имя для диктора; пока окно или поиск открыты, `.app` и `#tabbar` «заморожены» (`inert`), фокус внутри, после закрытия — на кнопке, которой открыли (`js/a11y.js`). «Сохранить» прилипает к низу (`.sh-foot`); на телефоне свайп вниз закрывает; «Назад» закрывает окно, а не приложение (`shHistOpen` / `shHistClose`); на ПК окно — плашкой по центру экрана (с 21 октября 2026, раньше — панель справа), на телефоне — снизу; изменённая форма с кнопкой сохранения спрашивает «Закрыть без сохранения?» (`SH_SAVE`, `shDirty`, `closeSheetAsk`), крестик закрывает сразу; Esc закрывает окно, карточку и отменяет перетаскивание.
- **Назад смахиванием от левого края** (телефон, 23 октября 2026): страница едет за пальцем, под ней снимок прошлой; дальше трети экрана или быстро — назад, иначе возвращается (`js/input.js`: `navSwipeStart` / `Move` / `End`, край 24 px).
